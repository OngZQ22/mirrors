# MIRRORS — *The Right to Be Bored*

A short, quiet, devastating pixel-art love story. About 20 minutes.
Two people on a night train, running for a coast that one of them will never see.

**▶ Play it here:** *(add your GitHub Pages link once it's on — see below)*

---

## How to play

- Click **start game**, tell the mirror your name, and step through.
- Choose with the **mouse**, or press **1** / **2**.
- Or say nothing at all — silence is always a real answer, and the story remembers it.
- **Space** / **Enter** advance the text. **Esc** pauses.
- Headphones strongly recommended.

At the end, the mirror takes your **PULSE** — a heartbeat drawn from the choices you actually
made, and a reading of what you are like to love.

## Built with

Plain **HTML, CSS and JavaScript** in a single file — no frameworks, no dependencies.
Canvas API for the mirror and the heartbeat, Web Audio API for the score, localStorage for saves.
